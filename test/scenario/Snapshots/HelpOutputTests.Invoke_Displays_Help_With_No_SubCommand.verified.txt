Description:
  Creates and extracts compressed, encrypted archive files.

Usage:
  archive <command>
  archive --help | -?

Commands:
  create       Creates an archive set from one or more input files.
  extract      Extracts an archive file or set.

Directives:
  [log-level=<level>]      Configures verbosity of output logging. <level> = trace|debug|information|warning
